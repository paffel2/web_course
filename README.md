# Веб-приложение для анализа и мониторинга показателей эффективности рекламных кампаний интернет-магазина автозапчастей на маркетплейсах

Курсовой проект по дисциплине «Интернет-технологии»

---

## 📌 Описание проекта

Специализированное веб-приложение для интернет-маркетологов и руководства интернет-магазина автозапчастей. Обеспечивает автоматизацию сбора, агрегации и глубокого анализа ключевых показателей рекламной эффективности в кабинетах маркетплейсов:
- **WB РФ** — рекламный кабинет Wildberries (Российская Федерация);
- **WB РБ** — рекламный кабинет Wildberries (Республика Беларусь).

### Ключевые показатели эффективности:
- **ДРР (Доля рекламных расходов, %)** — отношение затрат на рекламу к полученной выручке с учетом целевого порога рентабельности каждой кампании;
- **CPO (Cost Per Order, руб.)** — реальная стоимость привлечения одного оформленного заказа автозапчастей;
- **CR (Conversion Rate)** — конверсия из клика (перехода в карточку) в добавление автозапчасти в корзину ($CR_{cart}$) и в завершенный заказ ($CR_{order}$);
- **Показы (Impressions), Переходы (Клики, Clicks), CTR (Click-Through Rate, %) и CPC (Cost Per Click, руб.)**;
- **ROAS (Return On Ad Spend)** и **AOV (Average Order Value / Средний чек, руб.)**;
- **Маркетинговая воронка конверсий** (Показы рекламы $\rightarrow$ Переходы в карточку товара $\rightarrow$ Добавления в корзину $\rightarrow$ Заказы);
- **Интерактивные диаграммы (Chart.js)**: динамика ДРР и CPO по дням, структура выручки кабинетов (WB РФ vs WB РБ), соотношение затрат и выручки по дням;
- **Экспорт аналитических срезов в CSV (Excel)** и **Импорт суточных метрик из внешних файлов CSV**.

## 🛠 Технологический стек

- **Backend:** Python 3.10+, фреймворк Django 5.x (архитектура MVT, Django ORM, сервисный слой).
- **База данных:** SQLite (реляционная СУБД, файл `db.sqlite3`).
- **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6), фреймворк **Bootstrap 5**, иконки **Bootstrap Icons**.
- **Визуализация данных:** Библиотека **Chart.js** (Canvas-рендеринг, адаптивность, двойные оси значений).

## 🚀 Быстрый запуск

### 1. Установка зависимостей (при необходимости)

```bash
pip install -r requirements.txt
```

### 2. Запуск локального сервера разработки

```bash
python manage.py runserver
```

После этого откройте браузер по адресу:  
👉 **http://127.0.0.1:8000/**

В базу данных уже предзагружены тестовые пользователи:

| Роль | Логин | Пароль | Доступные функции |
|---|---|---|---|
| **Маркетолог / Аналитик** | `marketer` | `marketer123` | Просмотр дашборда, фильтрация по датам и кабинетам маркетплейсов, аудит кампаний, экспорт отчетов в CSV, импорт данных |
